Batch

Run several searches one after another as a single job. With 10 or more addresses the Census batch geocoder is used. Up to 200 searches. When the job finishes, download the results as a CSV.

File format. One search per line, no header: parcel address|parcel ID, for example 11205 TINDALL RD, ORLANDO, FL 32832|2824310000 00026 (the parcel ID may be left out). A CSV with a header row (address,parcel_id,state,county) also works, and is the way to search by parcel ID alone.
