Triage with Jev

The same sorting as the Triage tab (simple, medium, complex), but decided by the Jev model (TypeSafe) instead of fixed rules, shown next to the rule-based level. This is not a search run and makes no Claude call. Up to 300 rows.

How it works. 1. The free Census geocoder (one request) says whether each address is real and in which county, and code checks whether the county has an adapter. 2. Rows in an adapter county are simple by rule; Jev is not called for them. 3. For every other row Jev is given those facts plus the address and parcel ID text and answers five questions in one call: is the address real or junk, is the parcel ID well-formed, is a public portal likely, does one office bill the tax, and how difficult is the row (simple / medium / complex, with probabilities). 4. The row takes Jev's difficulty when its confidence reaches the threshold. Below it, the row keeps the rule-based level and is flagged needs Claude review. Counting, shares and token sums are done by code, not by Jev.
"Agrees with the rule-based level" is not the same as "accurate": accuracy needs real run outcomes to compare against.
