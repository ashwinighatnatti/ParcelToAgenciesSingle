Find the tax collecting agency

Start from a parcel address, a parcel ID, or both. Three stages run in order: validate the address, find and validate the parcel, find and validate the agency. A county with an adapter takes about a minute; other counties are researched by Claude on the web and can take a few minutes.

How an answer is arrived at

The trajectory. Every search records each step it takes. The result page summarises it by stage and lists every step, every website touched and every web search Claude ran. The audit file (Excel, on every result page) holds the same detail for checking.

  1. Validate the address: US Census Geocoder matches it; Census TIGERweb gives the county, city and school districts.
  2. Find / validate the parcel: Maricopa AZ and King WA are searched in the county's own GIS records; every other county is researched by Claude on the web.
  3. Find / validate the agency: for Maricopa AZ and King WA the county's tax statement page is opened, Claude reads the agency and the code checks the parcel number is on the page; for every other county Claude researches it on the web, so the answer is marked unverified.

The confidence score (0 to 100) is the points earned for the evidence at each stage, divided by the points possible. A parcel ID search has no address to check, so the address points are left out. If no agency is found the score is 0. Levels: {{ levels }}. The weights are a judgement, not a statistical calibration.
