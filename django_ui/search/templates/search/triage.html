Triage a batch

Sorts a batch into simple (easily accessible), medium (few steps) and complex before you run it. This is not a search: it makes no Claude call and costs $0. It uses one Census batch geocoder request (is each address real, and in which county?), whether the county has a scripted adapter, and whether the state has one tax office or several.

How a row is classified. Simple: the address matches and the county has an adapter (parcel and agency read from the county's own records). Medium: no adapter, but the state has one county-level collector (web research, 2 searches). Complex: the address does not match the Census geocoder, or the state has several collectors. The state classification is the draft in jurisdictions_config.json; it still needs checking with Operations. Estimated full-run costs come from runs already made: about $0.015 per adapter row, about $0.85 per web-research row, $0 for an address that does not match (the full run stops there). They are estimates, not guarantees.
